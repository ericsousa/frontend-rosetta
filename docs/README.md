# Documentation

This directory is the concept-first half of FrontEnd Rosetta. Comparative guides focus on equivalent intent rather than identical source code. The learning order is Angular → Next.js → React → Vue → Svelte, with Angular and Next.js prioritized for the upcoming seminar. Existing guides will be expanded incrementally.

The first guide is [Project initialization](fundamentos/01-project-initialization.md).

## Planned documentation rounds

1. **Foundations:** explain where React ends and Next.js begins, choose the learning scope, and expand the initialization guide.
2. **Components and UI:** compare templates, JSX, props, state, events, and client/server component boundaries.
3. **Navigation and data:** compare routing, product lists and details, HTTP requests, loading, empty results, and failures using the intended behavior of `loja`.
4. **Seminar preparation:** assemble a teaching sequence, a small reproducible demonstration, questions, and a verification checklist.

These are planned deliverables, not claims of implemented or verified features. Each round should record official references, tested versions, and which examples have actually been run. Next.js-specific server capabilities should be identified explicitly rather than treated as direct Angular equivalents.

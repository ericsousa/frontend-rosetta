# FrontEnd Rosetta

FrontEnd Rosetta is a comparative learning laboratory that studies equivalent frontend concepts and projects in Angular, React, Vue, and Svelte.

Angular follows the course work and is the starting point for each comparison. The other implementations translate the intended behavior into their own idiomatic ecosystems rather than reproducing Angular syntax literally.

Start with the [documentation](docs/README.md) and the [framework-neutral project specifications](projetos/README.md).

The Angular `loja` project is protected coursework during the semester. Its future React, Vue, and Svelte counterparts will preserve Portuguese user-facing language and domain examples.

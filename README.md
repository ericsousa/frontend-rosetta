# FrontEnd Rosetta

FrontEnd Rosetta is a comparative learning laboratory that studies equivalent frontend concepts and projects in Angular, Next.js, React, Vue, and Svelte.

Angular follows the course work and is the starting point for each comparison. The other implementations translate the intended behavior into their own idiomatic ecosystems rather than reproducing Angular syntax literally.

The next learning priority is Next.js, in preparation for a college seminar. Documentation rounds will explore Angular and Next.js first, including the React foundations needed to understand Next.js. Standalone React, Vue, and Svelte implementations remain part of the longer-term scope.

Start with the [documentation](docs/README.md) and the [framework-neutral project specifications](projetos/README.md).

The Angular `loja` project is protected coursework during the semester. Its future Next.js, React, Vue, and Svelte counterparts will preserve Portuguese user-facing language and domain examples.
